마린스키극장에서 - 인터랙티브 전화/메시지 웹사이트

[파일 안내]
- marinski_call_site_final.html : 메인 웹사이트 파일
- README.txt : 이 안내 파일

[실행 방법]
1. marinski_call_site_final.html 파일을 다운로드합니다.
2. 파일을 휴대폰 또는 PC의 웹 브라우저에서 엽니다.
3. 별도의 서버나 데이터베이스 없이 실행할 수 있습니다.

[주요 기능]
- 최근 통화 / 연락처 / 키패드 화면
- 연락처별 상세 화면
- 연락처에서 메시지 화면으로 이동
- 메시지 전송 기능
- 전송한 메시지의 읽지 않음 / 읽음 상태 표시
- Моя самая сладкая смерть 대화 기록
- 메시지 전송 후 읽음 처리 및 입력 중 표시를 이용한 자동 대화 연출
- 청첩장 링크를 누르면 청첩장 화면으로 이동
- 청첩장 결혼식 장소: 평양 경흥관 결혼식당.
- 리택기 동무 / 류대욱 대위 메시지 전송 기능
- 기존 통화 녹음 재생 연출
- Моя самая сладкая смерть 3회 통화 후 연결되는 특별 통화 연출

[주의]
이 사이트는 정적 HTML/JavaScript로 동작합니다. 실제 문자메시지나 전화가 외부로 전송되는 서비스가 아니며, 브라우저를 새로고침하면 일부 임시 상태가 초기화될 수 있습니다.
