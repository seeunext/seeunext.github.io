# 마린스키극장에서

스마트폰의 전화·연락처·메시지 앱을 모티브로 만든 인터랙티브 스토리 웹사이트입니다.

> **GitHub Pages용 정적 웹사이트**
>
> 별도의 서버, 데이터베이스, npm 설치 없이 `index.html` 하나로 실행됩니다.

## 🌐 GitHub Pages로 실행하기

### 1. Repository 만들기

GitHub에서 새 Repository를 만든 뒤 이 프로젝트 파일을 업로드합니다.

```text
마린스키극장에서/
├── index.html
└── README.md
```

### 2. 파일 업로드

이 저장소의 최상위(root)에 다음 두 파일을 넣습니다.

- `index.html` — 실제 웹사이트
- `README.md` — GitHub 저장소에서 프로젝트 설명으로 표시되는 파일

**중요:** `index.html`의 파일명을 다른 이름으로 바꾸지 마세요. GitHub Pages가 사이트의 시작 페이지로 사용합니다.

### 3. GitHub Pages 켜기

Repository에서:

`Settings` → `Pages`

로 이동합니다.

`Build and deployment`에서 다음과 같이 선택합니다.

- **Source:** `Deploy from a branch`
- **Branch:** `main`
- **Folder:** `/ (root)`

저장한 뒤 잠시 기다리면 GitHub Pages 주소가 생성됩니다.

## 📱 웹사이트 기능

### 전화

- 최근 통화 기록 확인
- 녹음된 통화 기록 재생
- 연락처에서 전화 걸기
- 키패드 사용
- `1`번 길게 누르기 기능
- `Моя самая сладкая смерть`에게 세 번째 전화를 걸었을 때 연결되는 특별 통화
- 특별 통화 종료 후 `상대방이 전화를 끊었습니다.` 표시

### 연락처

다음 연락처가 포함되어 있습니다.

- `리택기 동무` — 가시 아버지
- `류대욱 대위` — 류대욱 대위
- `Сукин сын, которого я любил` — 선우민 동무
- `Моя самая сладкая смерть` — 유빈

각 연락처에서 메시지 화면으로 이동할 수 있습니다.

### 메시지

#### `Моя самая сладкая смерть`

기존 대화 기록이 표시되며, 리현상의 시점으로 진행됩니다.

- 리현상이 보낸 메시지는 이름을 표시하지 않습니다.
- 상대방 메시지는 상대방 이름으로 표시됩니다.
- 새로운 메시지를 직접 보낼 수 있습니다.
- 전송 직후 `읽지 않음`이 표시됩니다.
- 일반 메시지는 3초 후 `읽음`으로 변경됩니다.
- 특정 메시지 이후에는 상대방의 `입력하는 중···` 상태가 표시됩니다.
- 이후 `저는 아직 소좌님 좋아해요.`라는 답장이 이어집니다.
- 이후 리현상이 보내는 메시지는 바로 `읽음`으로 처리됩니다.

대화 중 공유되는 청첩장 링크를 누르면 별도의 청첩장 화면이 열립니다.

청첩장에는 다음 결혼식 장소가 표시됩니다.

**평양 경흥관 결혼식당.**

청첩장 화면에서도 왼쪽 상단의 뒤로가기 버튼으로 메시지 화면으로 돌아갈 수 있습니다.

#### `리택기 동무`

기존 대화 없이 빈 메시지 화면으로 시작합니다.

메시지를 보낼 수 있으며 전송한 메시지는 `읽지 않음`으로 표시됩니다.

#### `류대욱 대위`

기존 대화 없이 빈 메시지 화면으로 시작합니다.

메시지를 보낼 수 있으며 전송한 메시지는 `읽지 않음`으로 표시됩니다.

#### `Сукин сын, которого я любил`

기존에 설정된 대화 기록을 확인할 수 있으며 새로운 메시지도 보낼 수 있습니다.

## 💬 메시지 화면 동작

메시지 화면에서는 왼쪽 상단의 `←` 버튼으로 연락처 화면으로 돌아갈 수 있습니다.

`읽지 않음` 표시는 메시지 오른쪽이 아니라 **말풍선 왼쪽**에 표시되도록 구성되어 있습니다.

## 📨 데이터 저장 방식

이 프로젝트는 서버나 데이터베이스를 사용하지 않는 정적 웹사이트입니다.

따라서 사용자가 새로 보낸 메시지나 통화 횟수 등의 일부 상태는 **현재 페이지가 열려 있는 동안만 유지**되며, 페이지를 새로고침하면 초기 상태로 돌아갈 수 있습니다.
