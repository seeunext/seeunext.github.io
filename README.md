# 마린스키극장에서 — 전화/문자 인터랙티브 웹사이트

스마트폰 전화 앱을 모티브로 만든 인터랙티브 스토리 웹사이트야.
별도의 서버나 데이터베이스 없이 **HTML 한 파일만으로 실행**되도록 만들었어.

## GitHub Pages에 올리는 방법

### 1. 저장소 만들기
GitHub에서 새 Repository를 만든다.

### 2. 파일 2개 업로드
저장소 최상단(루트)에 아래 두 파일을 그대로 올린다.

- `index.html` ← **가장 중요. 사이트의 시작 파일**
- `README.md` ← 설명 파일

`marinski_call_site_final.html`이라는 이름으로 올릴 필요는 없어. GitHub Pages가 기본 시작 페이지로 인식하도록 반드시 `index.html`을 사용하면 돼.

### 3. GitHub Pages 켜기

Repository에서:

`Settings` → `Pages`

로 들어간 뒤 다음처럼 설정한다.

- **Source:** `Deploy from a branch`
- **Branch:** `main`
- **Folder:** `/ (root)`

저장하면 잠시 후 GitHub Pages 주소가 생성된다.

## 주의사항

- 파일 이름은 정확히 `index.html`이어야 한다.
- `index.html`과 `README.md`는 같은 저장소의 최상위 폴더에 넣는다.
- 별도의 이미지 파일, CSS 파일, JavaScript 파일이 필요하지 않다. 현재 버전은 전부 `index.html` 안에 들어 있다.
- 서버나 데이터베이스를 사용하지 않기 때문에 새로고침하면 현재 페이지에서 입력한 메시지나 통화 횟수 등의 임시 상태는 초기화된다.
- GitHub Pages에 올린 뒤에도 전화/문자 UI는 정적 웹페이지로 작동한다.

## 현재 구현된 기능

### 전화
- 최근 통화 기록
- 통화 기록을 눌러 녹음된 통화 내용 재생
- 각 통화 대사가 약 3초 간격으로 한 줄씩 나타남
- 연락처에서 전화 걸기
- 연락처의 모든 전화는 기본적으로 응답 없음
- `Моя самая сладкая смерть`는 세 번째 전화에서 연결
- 연결 후 대사가 약 3초 간격으로 진행
- 마지막 대사 후 3초 뒤 `상대방이 전화를 끊었습니다.` 표시 후 통화 종료
- 키패드에서 `1` 길게 누르기로 `Моя самая сладкая смерть` 단축 전화 가능

### 연락처
현재 연락처:

- `Моя самая сладкая смерть` — 유빈 · 단축번호 1
- `리택기 동무` — 가시 아버지
- `류대욱 대위` — 류대욱 대위
- `Сукин сын, которого я любил` — 선우민 동무

각 연락처를 누르면 상세 화면에서 전화 또는 메시지를 선택할 수 있다.

### 메시지
모든 연락처에서 메시지 화면으로 들어갈 수 있다.

- 왼쪽 위 뒤로가기 화살표
- 기존 대화 기록 유지
- 메시지 직접 입력 및 전송
- Enter 키로도 전송 가능
- 내가 보낸 메시지는 오른쪽에 표시
- `읽지 않음` 표시는 내가 보낸 말풍선의 **왼쪽**에 표시

#### Моя самая сладкая смерть
대화 기록:

- `<7일 전>`
  - 리현상: `유빈아.`
  - 상대방: `소좌님.`
  - 리현상: `···.`
  - 리현상: `나 말구 좋은 사람 만나라. 응?`
- `<5일 전>`
  - 상대방: `소좌님.`
  - 상대방: `그, 그러니까.`
  - 상대방: `···가시 아버지 때문이죠?`
  - 리현상: `이유는 없서.`
  - 리현상: `언젠가 할 결혼이기두 하구.`
  - 상대방: `하지만···.`
- 청첩장 링크
- `<2일 전>` `결혼 축하드려요.`
- `<어제>` `행복하세요.` / `저는, 잊으시고요.`

청첩장 링크를 누르면 별도의 청첩장 화면으로 이동한다.

청첩장에는:

- `리현상 · ■■■`
- 결혼식 장소: **평양 경흥관 결혼식당.**
- 북한식 청첩장 분위기의 디자인
- 왼쪽 위 뒤로가기 버튼

유빈에게 처음 메시지를 보내면:

1. 내가 보낸 메시지가 `읽지 않음`으로 표시됨
2. 3초 후 `읽음`으로 변경
3. 그 1초 후 `입력하는 중···` 표시
4. 약 4초 후 유빈의 메시지 `저는 아직 소좌님 좋아해요.`가 **내가 방금 보낸 메시지 바로 다음**에 표시됨
5. 그 이후 내가 보내는 메시지는 바로 `읽음`으로 표시됨

#### 리택기 동무
- 기존 메시지는 없음
- 메시지 전송 가능
- 내가 보낸 메시지는 계속 `읽지 않음`

#### 류대욱 대위
- 기존 메시지는 없음
- 메시지 전송 가능
- 내가 보낸 메시지는 계속 `읽지 않음`

#### Сукин сын, которого я любил
기존 대화가 들어 있으며 메시지를 추가로 보낼 수 있다.

## 데이터 저장 여부

현재 버전은 브라우저에서 실행되는 정적 페이지다.

따라서:

- 실제 문자/전화가 전송되는 것은 아니다.
- 서버에 메시지가 저장되는 것은 아니다.
- 페이지를 새로고침하면 사용자가 추가한 메시지와 통화 횟수 같은 임시 상태가 초기화된다.
- 실제 계정, 로그인, 문자 발송 기능을 사용하려면 별도의 백엔드가 필요하다.

## 파일 구성

```text
Repository/
├── index.html
└── README.md
```

이 두 파일만 GitHub 저장소 최상단에 올리면 된다.
